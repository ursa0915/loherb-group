## 四、Open Graph + Twitter Card（社群分享）

每頁 `<head>` 都需加入：

```html
<!-- Canonical -->
<link rel="canonical" href="https://party.loherb.com.tw/<頁面路徑>" />

<!-- Hreflang (zh ↔ en) -->
<link rel="alternate" hreflang="zh-Hant" href="https://party.loherb.com.tw/<zh-path>" />
<link rel="alternate" hreflang="en" href="https://party.loherb.com.tw/en/<en-path>" />
<link rel="alternate" hreflang="x-default" href="https://party.loherb.com.tw/<zh-path>" />

<!-- Open Graph -->
<meta property="og:type" content="website" />
<meta property="og:site_name" content="日光時刻 LOHERB Moments" />
<meta property="og:locale" content="zh_TW" />
<meta property="og:locale:alternate" content="en_US" />
<meta property="og:url" content="https://party.loherb.com.tw/<path>" />
<meta property="og:title" content="<同 title>" />
<meta property="og:description" content="<同 description>" />
<meta property="og:image" content="https://party.loherb.com.tw/<og-image-path>" />
<meta property="og:image:width" content="1200" />
<meta property="og:image:height" content="630" />

<!-- Twitter Card -->
<meta name="twitter:card" content="summary_large_image" />
<meta name="twitter:title" content="<同 title>" />
<meta name="twitter:description" content="<同 description>" />
<meta name="twitter:image" content="<同 og:image>" />
```

## 八、技術 SEO 待辦清單

### A. 必做（一週內）

- [ ] **所有頁面加入 canonical URL** 防止重複內容懲罰
- [ ] **所有頁面加入 OG + Twitter Card** 改善社群分享外觀
- [ ] **首頁加 LocalBusiness JSON-LD** 助於 Google Knowledge Panel
- [ ] **產生 sitemap.xml + robots.txt**
- [ ] **更新所有頁面 title + description** 套用本文件第三節公式
- [ ] **每張內容圖片補 `alt` 屬性** 含關鍵字（如 alt="宜蘭網美咖啡廳玻璃屋內景"）
- [ ] **hreflang 標籤** 在中英版互相連結

### B. 中期（一個月）

- [ ] **menu.html 加 Menu Schema**
- [ ] **venues.html 加 EventVenue Schema**
- [ ] **journal.html 每篇文章加 BlogPosting Schema**
- [ ] **註冊 Google Search Console** 並提交 sitemap
- [ ] **提交至 Bing Webmaster Tools**
- [ ] **註冊 Google Business Profile**（如尚未）建立完整商家資料

### C. 內容 SEO（長期）

- [ ] **journal.html 持續發文** — 主題如「宜蘭網美咖啡廳推薦」、「冬山下午茶 5 家精選」、「玻璃屋咖啡日落時段」
- [ ] **每篇文章 1500+ 字**，內含 H2/H3 結構、關鍵字、圖片 alt
- [ ] **內部連結策略** — journal → cafe.html / menu.html / book.html
- [ ] **取得在地媒體連結** —Klook、KKday、各旅遊部落客合作
- [ ] **Google 評論累積至 500+** 提升 LocalBusiness 權重

### D. 效能 SEO（影響排名）

- [ ] **圖片轉 WebP/AVIF 格式** 縮小 60-80% 容量
- [ ] **延遲載入** `<img loading="lazy">` 已部分採用
- [ ] **CDN 啟用** Firebase Hosting 預設已啟用
- [ ] **行動裝置友善度 100/100** Google Mobile-Friendly Test
- [ ] **Core Web Vitals**：LCP < 2.5s、CLS < 0.1、INP < 200ms
